📱💻 端末間で「投稿済み」を同期する

ここで設定しなくても今まで通り使えるけど、設定すると「投稿済みにする」を押した記録がこのGitHubリポジトリに保存されて、他の端末にも反映されるようになるよ(反映まで1分前後かかることがある)。
未設定のままだと、この端末だけの記録になる(=他の端末では投稿済みか分からず、重複ポストしやすい)。

GitHubのFine-grained personal access token作成ページ で、「Repository access」をこのリポジトリのみに限定し、「Permissions → Contents」を Read and write にして発行したトークンを貼り付けてね。
トークンはこの端末のブラウザ内だけに保存され、他には送信されない(GitHubへの同期通信を除く)。他人と共有する端末では設定しないこと。
